1. ConfigMap "{{ .Values.config.auditLogs.input.existingConfigMap }}" is created by the chart when createConfigMap is true.
   To use your own: set createConfigMap to false and create the ConfigMap manually.

2. Ensure the Secret "{{ .Values.elasticsearch.existingSecret }}" exists in {{ .Release.Namespace }}
   with keys {{ .Values.elasticsearch.usernameKey }} and {{ .Values.elasticsearch.passwordKey }}.

3. Audit pod (audit-logs + sidecar):
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

   Deploy rbac-exporter in the Prometheus cluster using k8s/exporter-standalone.yaml for metrics.
